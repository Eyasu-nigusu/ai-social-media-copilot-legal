Privacy policy

What the current AI Social Media Copilot MVP accesses and how it handles that information.

Last updated October 24, 2026

What the app does

AI Social Media Copilot is an early-stage analytics tool for Instagram professional accounts (Creator and Business). When connected, it uses Meta’s Instagram API to retrieve available profile information, posts, post or account insights where available, and comments on the connected account’s own posts where Meta makes them available.

The dashboard uses retrieved data for display and for transparent, rule-based comparisons and experiment suggestions. These suggestions are not generated by an external AI service and are not guarantees of future results.

Information processed

  • Account information: Instagram user ID and username.
  • Post information: media ID, caption when available, media type, permalink, and timestamp.
  • Insights: metrics Meta returns for a post or account, which can vary by media type and availability.
  • Comments: comment ID, text, username, timestamp, and like count when returned by Meta.
  • Access token: the credential used by the server to make authorized requests to Meta.

The app processes this information to connect the account, display posts and available measurements, and produce the dashboard’s comparisons and content experiments. It does not intentionally request data beyond these current features.

How information is handled and protected

The Instagram access token is currently read from a server-side environment variable. Requests to Meta are made by the server; the token is not intended to be sent to browser code or included in dashboard responses. The token should not be committed to source control or shared in support requests.

The current MVP has no database and does not implement persistent account storage or an automated data-deletion system. Instagram information is fetched when the app requests it and may be present temporarily in server or browser memory while the dashboard is being used. The app returns selected profile, post, insight, and comment fields to the connected dashboard for display.

These are current implementation details, not a claim of a security certification or a guarantee against every security risk. Meta separately processes data under its own terms and privacy practices.

Retention and deletion requests

Because the MVP has no database, it is not designed to retain retrieved Instagram content in an app database. The access token remains in the operator’s server environment until the operator removes it. Temporary runtime, browser, or hosting logs may exist depending on how the app is run; the MVP does not provide a self-service deletion workflow.

To request removal of the server-side token or ask about data associated with your use, contact the person or operator who provided access to this app. Include your Instagram username and describe the request. Do not send your password or access token. See Data deletion for steps to revoke the app’s access through Instagram.

Changes and questions

This policy describes the current MVP and may be updated as its functionality changes. No dedicated support email or legal entity is currently listed for this project; use the access-provisioning channel to reach its operator.
